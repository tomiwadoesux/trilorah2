# Add images and videos to Trilorah

An announcement poster fills the screen. A background sits behind the words. Decide which one you need before choosing an image.

Trilorah supports both, but the controls have different effects. Use the media path for something people should look at on its own, and the background path for something behind scripture or lyrics.

## Import a local file

Open **Media** and choose **add from laptop**, or drop the file into the media library. Select the intended picture or video and wait for the import result.

Find the imported item and preview it. If you selected several files, check which ones actually arrived. A canceled picker or failed import does not add usable content.

For video, rehearse the opening, playback, and ending on the equipment you will use. The thumbnail only shows one frame. (An extremely short rehearsal.)

## Find something online

Open **Online** and search for a concrete subject, such as “green pasture” for a Psalm 23 reading. Review the image itself: a relevant subject can still be too busy behind a passage.

Online stock search needs a network connection and an available provider. If a key is missing, open **Settings → API keys** and add the appropriate Pixabay or Pexels key. Save it, then return and try a search. A saved key confirms the setup entry; the search checks whether the provider accepts it.

Select a result and wait for the download to finish. Confirm the item appears before relying on it. A thumbnail in the search results is not yet a downloaded file.

## Show a visual as the main content

Select an item on Media's **media** shelf to stage it in preview. Check the image, crop, and intended output, then use **Go live** when it should appear.

The separate **Online** tab also stages its selected material as standalone media. Use that for an event poster or a visual the speaker wants the room to see on its own.

## Put an image behind the words

Use the **themes** shelf inside Media, or drag suitable media onto preview to prepare it as a background. Check it with the actual scripture or lyrics.

Keep these actions distinct:

- Single-clicking a theme card prepares its background in preview.
- Double-clicking a theme card changes the live background.
- Dropping a background onto **LIVE** changes the live background directly.

While preparing, work in preview. If the image competes with the words, adjust the theme or choose a simpler visual. Readable text is the reason that background is there.

## Check the finished material

Before the service, open the visuals you plan to use. Keep a usable local alternative when an online search or download is unfinished.

When moving to another computer, inspect what the service package includes. A remote link does not automatically become an offline copy simply because it appears in the service.
