# Add images and videos to Trilorah without confusing media and backgrounds

Before adding a visual, decide what job it should do. An announcement image can be the whole screen. A quiet image behind scripture supports the words already on screen.

Trilorah supports both uses, with different preparation paths. Choosing the right one keeps a background change from becoming an unexpected replacement for the content you meant to show.

## Import a file from your computer

Open **Media** and use **Add from laptop**, or drop a supported file from your file browser into the media workflow. Choose the intended picture or video.

Wait for the import result, then find the item in the library and select it to preview. Canceling a file picker does not import anything, and selecting several files is not proof that every file succeeded. Check the actual results.

For a video, test more than the thumbnail. During rehearsal, check the opening, playback, and ending using the equipment that will present it.

## Search for an online visual

Open **Online** and search for a concrete subject. For a Psalm 23 sermon, “green pasture” or “sheep hillside” gives the search something specific to find. Review the result as an image choice; the subject alone does not make it suitable behind a long passage.

Online search needs a network connection and an available media provider. If the app reports that a provider is unavailable or needs configuration, resolve that condition or use a local file already on the computer.

When you choose a stock result, Trilorah downloads it before adding the item. Wait for that operation to finish and confirm the item appears. A result thumbnail in the search is not yet a saved local visual.

## Use media as the main content

Choose a media-library item to stage it in preview. Check the crop, content, and intended output before using **Go live**.

The separate Online library tab also stages selected material as standalone media. If you want an image behind words, use the background path instead of assuming any selected picture becomes a theme.

For example, a full-screen event poster belongs in a media or slide moment. It probably should not become the background behind the next scripture reading.

## Put a visual behind words

Use the **themes** shelf in Media, or drag suitable media onto the preview to use it as a background. Check the result with the actual words you intend to show.

A single theme-card click prepares the background in preview. Double-clicking a theme card or dropping a background onto **LIVE** changes the live background. Use the preview path while you are preparing.

If the visual competes with the words, adjust the theme or choose a simpler image. A background can be beautiful on its own and still make a poor reading surface.

## Verify the prepared result

Before the service, open every planned visual and inspect it. Keep a usable local alternative for material you cannot finish downloading. If you are transferring the service, review what the service package contains rather than assuming a link has become an offline copy.
