# Help Trilorah recognise your preacher’s references

When the same book name is repeatedly misheard, keep one clear example. That gives you something to correct and test again.

Trilorah's preacher profiles include a sound check, recognition review and teaching controls. They help you work on specific mistakes instead of changing settings without knowing what failed.

## Select the preacher

Open the preacher's profile and choose **set for today** when they are the current speaker. Create a profile first if needed.

Check the name before saving teaching or corrections. Those examples should belong to the person whose speech you are reviewing.

## Run a sound check

Open **sound check & review**, select an offered exercise and choose **Start sound check**. Have the preacher read the reference naturally into the microphone or feed you plan to use for the service.

Wait for a result before moving to the next exercise, then choose **Stop sound check** when finished.

This check uses a local speech engine, even if regular services use a cloud provider. The first check may need to download the local engine and model. Results arrive in roughly five-second chunks plus processing time, so allow a pause.

A successful check covers that input and those spoken examples. If the service uses a different microphone or speech provider, test that setup too.

## Review a real example

In **Review recognition**, read the transcript and suggested passage before answering:

- **Correct** confirms a valid detection.
- **Wrong reference** lets you enter the intended passage and **Save correction**.
- **Not a reference** rejects a mistaken detection.
- **Can’t tell / new passage** leaves the example unverified when the context is unclear.

Use **Add missed example** when you can supply the words from a reference the app missed. Review that example and add the intended reference when you know it.

Saved corrections can help when the same words are heard again. Only verified answers affect readiness; an empty review list or a higher indicator does not prove every reference was caught.

## Put teaching in the right place

The **teaching** page separates three kinds of information:

| Section | What belongs there |
|---|---|
| **sounds like** | A recurring misheard book name and the correct Bible book |
| **their words** | Names and church vocabulary used in local transcript matching; online speech can also use them as hints |
| **ignored after a verse** | Habitual words after a reference that should not be read as part of it |

For example, if the transcript repeatedly renders “Romans” as “rawmeans” before a chapter number, that belongs in **sounds like**. Use a mistake you have actually observed, then repeat the reference to check the effect.

Treat each saved change as something to test. Repeat the actual reference after adding it; saving the entry alone does not confirm that the next attempt will be recognised correctly.

## Keep checking before presenting

Improved readiness does not turn scripture suggestions into automatic projection. The operator still chooses when to send a suggested passage live. The separate voice-command controls have their own settings; do not treat a recognition score as permission to enable them.

For the listening process, read [how scripture recognition works](04-how-scripture-recognition-works.md). If the transcript is missing altogether, use [the audio troubleshooting guide](13-when-trilorah-cannot-hear-you.md) first.
