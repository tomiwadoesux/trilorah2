# Put the right content on the right screen in Trilorah

A room can have several screens with different jobs. The congregation needs lyrics and scripture. A speaker may need a stage view. A timer needs a place where the right person can see it.

In Trilorah, use the dashboard's **Outputs** tile to check two things for each output: its **job** and its **display**. The job describes what the output does. The display is where its window appears.

## Begin with the connected hardware

Connect the projector or display to the computer and make sure the operating system recognizes it. Turn on the physical screen and select its intended input.

Open Trilorah's dashboard and expand **Outputs**. In the desktop app, the available displays come from the computer. If the display is not listed, changing content in the library will not fix the hardware connection.

Browser design previews can show sample screens. Use the desktop app and the actual room hardware for this check.

## Assign a job and a display

Find the output you want to configure. Use **job** to select the intended role: projector, stream, stage, or timer. Use **display** to choose its destination.

The **automatic** choice assigns external screens in order. A named display makes a deliberate assignment when you know which connection serves the room. **No screen — off** closes and disables that output.

Read the status text after making the change. An output shown as a window on the laptop is different from an output placed on a dedicated external display.

Make these changes during setup. They can move or close an output window that is already open.

## Check it with recognizable content

Prepare a simple test slide with a title such as “Projector check.” Send it live while the room is in rehearsal, then look at the destination screen.

Check more than whether something appeared:

- Is it the screen you intended?
- Can the entire slide be read without clipped edges?
- Is the text large enough from the back of the room?
- Does the live output match the item you sent?

Repeat for any other output your service needs. A correct laptop preview does not confirm the room display, and an open output window does not prove a projector is switched to the right input.

## Adjust layout after the destination is right

**Settings → Displays & output** contains preferences such as stream layout, stage clock information, background fit, and background position. Use those for presentation behavior after assigning the actual displays from the dashboard.

A stream output is a presentation output role. Selecting it does not, by itself, configure an entire internet broadcast or an external streaming application.

## If the content appears in the wrong place

Return to **Outputs** and compare the job and display with the physical connections. If a cable was removed or reconnected, check the list again. Read any output notice rather than assuming a previous assignment still describes the room.

If the destination is right but the wrong material appears, check what is live in the operator workspace. Preparing another item in preview is a separate action from sending it.

Once the screens are ready, finish [the first-service rehearsal](02-first-service-checklist.md). For text that looks good on the laptop but is difficult to read in the room, use [the readability guide](12-make-projected-words-readable.md).
