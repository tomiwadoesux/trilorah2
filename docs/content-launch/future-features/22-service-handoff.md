# The next volunteer needs more than a file name.

“Use the latest one” is a surprisingly demanding instruction when three files are called final.

Trilorah's **.tri** files let you package selected service resources for another computer or operator. Choose the run and the songs, media, presentations, and themes it needs, give the file a useful name, and check the save result.

That gives the next volunteer a prepared service to open and rehearse. It also makes the handoff concrete: which file to use, what's included, and what still needs attention.

## Send the material the service uses

Imagine you've prepared Sunday's run at home. It includes the opening reading, three saved songs, an announcement deck, and a local video. Before saving, review the package selection so those resources are included. After transferring it, open it on the presentation computer and check the items there.

A local asset can travel in the package. An online link can still depend on an online source. Read warnings and test the important media on the receiving machine; a successful save isn't proof that every linked resource will play there.

## Choose how to bring it in

Use **Open .tri** to continue the service from the file. Opening can replace the current service, so save work you want to keep and read the replacement confirmation.

Use **Import from .tri** to bring selected material into work already on the computer. That is useful when another volunteer sends a song or a group of resources rather than a complete replacement service.

After the first deliberate save, Trilorah can autosave changes to the current file's included content. Keep an eye on its save state, especially after adding material that wasn't part of the original selection.

## Finish the handoff in the room

Check the run, lyrics, slides, and critical media on the receiving computer. Then check that computer's screen and audio connections. The service file carries prepared content; the room still needs its own rehearsal.

Leave one useful note with the file: what was checked and anything unresolved. Follow [save and transfer a service](../articles/11-save-and-transfer-a-service.md) for the complete handoff.
