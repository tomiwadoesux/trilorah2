# Future feature preview copy

Three optional short previews per article. These are drafts for a website card, an owned-channel excerpt, or a caption next to a verified demo. They have not been posted. Choose one option for a placement; do not stack all three or strip away a requirement when repurposing. Publish only after the corresponding release gate passes.

## 17 · Mobile remote

1. **Your phone has been promoted.** (You should probably thank us.) Pair it with Trilorah on the same network to control prepared content while the desktop runs the service. [Meet the remote](17-mobile-remote.md).
2. Check a lyric slide from the back row, then advance it from your paired phone. Trilorah's desktop stays connected; the presentation controls come with you. [See mobile controls](17-mobile-remote.md).
3. Scripture, saved lyrics, slides, and media on one phone remote. Pair on the same network, approve on the desktop, and rehearse before the service. [Start here](17-mobile-remote.md).

## 18 · Scripture catches

1. The preacher names a passage you didn't prepare. Trilorah can suggest a match from the speech it receives; you check it and choose whether to send it live. [Meet scripture catches](18-scripture-catches.md).
2. A reference gives Trilorah an address. A quotation gives it words to match. Both can lead to a passage for you to review. [See how catches work](18-scripture-catches.md).
3. Scripture recognition should leave you with a useful next action. Check a suggestion, send it live deliberately, or use a manual search when the match isn't there. [Read the feature story](18-scripture-catches.md).

## 19 · In-app guide

1. “Open the settings” could be more helpful. Trilorah's guide can point out supported controls, demonstrate a step, or wait while you try it. [Choose how to learn](19-in-app-guide.md).
2. Choose **Show me** or **I'll do it**. The guide follows prepared workflows for tasks such as scripture lookup, media, audio, and service preparation. [Meet the in-app guide](19-in-app-guide.md).
3. Missing an image-provider key? The supported image guide can take you to setup, retain your query, and help you continue after you save it. [See the example](19-in-app-guide.md).

## 20 · Programme import

1. You already typed the programme once. Paste it into Trilorah, check the proposed rows, and start preparing the content for each segment. [Bring in your programme](20-programme-import.md).
2. A message or an image can be the starting point for your service run. Review the interpretation before adding it, then attach the material you'll present. [See the workflow](20-programme-import.md).
3. Welcome. Worship. Sermon. Closing. Start with the order you have, correct the proposed rows, and build a run you can rehearse. [Try the example programme](20-programme-import.md).

## 21 · Preacher corrections

1. A repeated recognition mistake deserves a specific correction. Trilorah keeps reviewed examples and targeted teaching with the selected preacher. [See what to teach](21-preacher-corrections.md).
2. Check the heard words, confirm the intended passage, and save the feedback you can verify. Then test it again. [Review a recognition example](21-preacher-corrections.md).
3. **sounds like**, **their words**, and **ignored after a verse** do different jobs. Choose the teaching control that fits the mistake. [Read the short explanation](21-preacher-corrections.md).

## 22 · Service handoff

1. “Use the latest one” needs a little more detail. Package the selected service resources in a .tri file, name it clearly, and check it on the receiving computer. [Make the handoff](22-service-handoff.md).
2. Prepare the run on one computer. Open the package on the next and check the songs, slides, and important media before the service. [See how the handoff works](22-service-handoff.md).
3. Open a packaged service, or import selected resources into existing work. Choose the action that matches the handoff, then rehearse the result. [Meet .tri service files](22-service-handoff.md).
