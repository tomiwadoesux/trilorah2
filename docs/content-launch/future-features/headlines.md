# Future feature headlines

Draft alternatives, not individually approved or published. Number 1 is the current article title. Literal alternatives are included for search, navigation, or a quieter page treatment. Keep capability requirements in the description or opening; a playful headline cannot carry them alone.

3. Check the slides from a seat.

The optional aside “(You should probably thank us.)” belongs to title 1's current draft. Do not stack it with another joke. The remote still needs the connected desktop and same network. “Your next slide is a tap away” refers to explicit remote controls, not autonomous slide selection.
