Trilorah's dashboard and libraries now have new illustrated empty states, more balanced layouts on smaller screens, and smooth expanding cards that keep their spacing as neighbouring cards resize.

### What's new

- Added light SVG artwork across the run of service, Scripture, songs, slides, media, online search, and dashboard. Empty card headings are centred, with descriptions and actions beneath the artwork.
- Refined the dashboard hover: cards expand left or right with gentle easing, and adjacent cards resize with them to preserve the gap.
- Improved artwork sizing, text, buttons, and scrolling on compact windows. Added Appearance and Language cards to the dashboard.
- Added animated display connections, a globe that rotates on hover, and a pocket watch that follows the device's clock. The display illustration shows the latest Scripture reference, starting with 1 Peter 4:10.
- Improved empty and error states in the Scripture library. Translation selection remains available when the current version has no content.
- Expanded Scripture recognition for quotations, Bible stories, and allusions, with local models and better handling of revised speech. Added sermon-start controls and detection.
- Corrected KJV verse numbering using an explicitly numbered source, with validation before replacing the Bible data.
- Updated song discovery and editing, slide text controls, programme scanning, and TRI package handling.
- Bundled verified local recognition models and English OCR data in the installers.

**Windows:** download the `.exe`. If Windows shows “Windows protected your PC”, choose **More info → Run anyway**. Add a Deepgram key in Settings to use cloud speech recognition.

**Mac (Apple Silicon):** download the `.dmg`. On first launch, **right-click the app → Open**.

PowerPoint import requires LibreOffice and Poppler (`pdftoppm`) on the computer running Trilorah.

Validation: production build, TypeScript checks, and 1,507 tests. Connection tests were rerun with permission to open local test ports.
