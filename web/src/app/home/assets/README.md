- `companion-*.png`: the production `live/[slug]/CompanionClient.tsx` and its child components, captured at 390 × 844 on 2026-10-10. The reading-options capture is a full viewport capture, framed around the actual panel with CSS in the landing page.

The landing scene switches between these captures using four accessible buttons placed over the captured bottom tabs. The other controls in the image are illustrative. Refresh these captures when the production interface changes.
