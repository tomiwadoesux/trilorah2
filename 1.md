# Summary of the Last Four Dashboard Design Chats

Date: September 28, 2026

## 1. Widen the Sermon Notes card

The dashboard layout was rebalanced to give **Sermon Notes** more room:

- Reduced the combined width used by **Readiness** and **Connected**.
- Moved **Notifications** farther left.
- Increased the width of **Sermon Notes**.
- Redesigned its empty state using the existing animated notes artwork.
- Enlarged and centered the animation inside the card.
- Kept the card interactive so it still opens the complete sermon-notes view.

## 2. Simplify the Sermon Notes message

The empty-state copy was shortened:

- Removed “Every message, ready to keep.”
- Kept: “Points, scriptures and quotes appear as the sermon is preached.”
- Increased the text width so the description fits on fewer lines.

## 3. Improve the animation transition

The top edge of the animated notes artwork previously stopped at a visible hard line. A vertical mask gradient was added so the artwork fades into the card background instead of being abruptly clipped.

## 4. Sharpen the fade and redesign Outputs

The fade at the top of the Sermon Notes animation was tightened so the transition is shorter and more defined.

The **Outputs** card was also redesigned:

- Replaced the generic rectangular placeholder with a recognizable monitor SVG.
- Added different marks inside the monitor for projector, stream, stage and timer roles.
- Added a small status light and monitor stand.
- Used a dashed screen outline when an output only exists as a window on the laptop.
- Added contextual guidance such as “Click to manage this screen” and setup instructions for outputs without a display.
- Preserved the existing screen paging controls and output settings behavior.
